# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Build a small FastAPI application that exposes a simple REST API for managing data. Students will practice creating endpoints, handling JSON requests, and returning structured responses from Python code.

## 📝 Tasks

### 🛠️ Create the FastAPI app

#### Description
Set up a FastAPI project with a basic app instance and at least one route that returns JSON data.

#### Requirements
Completed program should:

- import and initialize FastAPI
- create an application instance
- define at least one GET route
- return structured JSON data using Python dictionaries
- run the app locally with a development server

### 🛠️ Add CRUD-style endpoints

#### Description
Extend the app with multiple routes so it can create, read, update, and delete sample items such as books, tasks, or students.

#### Requirements
Completed program should:

- define a route to list all items
- define a route to create a new item
- define a route to retrieve a single item by ID
- define a route to update an existing item
- define a route to delete an item
- return appropriate status codes and JSON responses
- validate incoming request data using a model or basic checks
